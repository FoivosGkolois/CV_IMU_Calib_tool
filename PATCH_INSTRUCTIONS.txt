HARDWARE RUN ORDER
1. Run 08_SETUP_VISION_IMU_PC.bat
2. Run 10_TEST_VISION_IMU_PC.bat
3. In Arduino IDE upload exactly:
   standalone_tools/vision_imu_calibration/arduino/uno_r4_dual_imu_stream/uno_r4_dual_imu_stream.ino
4. Close Arduino Serial Monitor.
5. Run 11_RUN_VISION_IMU_SYNC_PC.bat
6. Enter the UNO R4 COM port, e.g. COM3.
7. In the browser wait for:
   - Runtime RUNNING
   - IMU state CONNECTED
   - Thigh READY and Shank READY
   - IMU rate close to 100 Hz after recording starts
8. Select Left or Right leg manually.
9. Start recording, stay still 5 s, perform 5 slow flexion-extension cycles, then Stop.

UNO R4 BUS NOTE
The sketch defaults to UNO R4 WiFi Modulino/Qwiic wiring on Wire1.
For sensors on normal SDA/SCL pins or UNO R4 Minima, set IMUCAL_USE_WIRE1 to 0.
