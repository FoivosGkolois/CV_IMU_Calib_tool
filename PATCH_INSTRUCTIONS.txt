REQUIRED RUN ORDER
1. Run 08_SETUP_VISION_IMU_PC.bat once again.
   This adds PyYAML and Matplotlib to the isolated .venv-vision environment.
2. Run 10_TEST_VISION_IMU_PC.bat.
3. Upload the existing standalone UNO R4 sketch:
   standalone_tools/vision_imu_calibration/arduino/uno_r4_dual_imu_stream/uno_r4_dual_imu_stream.ino
4. Close Arduino Serial Monitor.
5. Run 11_RUN_VISION_IMU_SYNC_PC.bat.
6. In the web page:
   - press Refresh under UNO R4 raw IMU stream,
   - select the UNO R4 COM port,
   - press Connect,
   - wait for CONNECTED, both sensors READY, and IMU estimator VALID.
7. Select the camera-near leg explicitly.
8. Record 5 seconds stationary plus five slow flexion-extension cycles.
9. Press Stop and inspect the generated session folder.
