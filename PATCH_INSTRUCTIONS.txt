Vision-IMU manual COM connection and camera profile patch

BASELINE
Current Thesis_master after applying the Dual-IMU Sync and Fast Webcam Initialization patches.

AFFECTED AREA
- PC calibration web UI
- Standalone UNO R4 serial connection lifecycle
- Live camera profile switching
- Setup/test launchers and targeted tests

UNCHANGED
- UNO R4 IMUCAL firmware protocol
- Production serial TELEM
- STM32 production firmware
- Motor, safety, control, estimator, and logger contracts

COPY / REPLACE
Extract this ZIP into the current Thesis_master root.
Keep the folder structure and replace matching files.
No file is deleted.

REQUIRED RUN ORDER
1. Run 08_SETUP_VISION_IMU_PC.bat once.
   This installs/verifies pyserial inside .venv-vision.
2. Run 10_TEST_VISION_IMU_PC.bat.
3. Upload the standalone UNO R4 sketch:
   standalone_tools/vision_imu_calibration/arduino/uno_r4_dual_imu_stream/uno_r4_dual_imu_stream.ino
4. Close Arduino Serial Monitor.
5. Run 11_RUN_VISION_IMU_SYNC_PC.bat.
6. In the web page:
   - press Refresh under UNO R4 raw IMU stream,
   - select the UNO R4 COM port,
   - press Connect,
   - wait for CONNECTED and both sensors READY.

CAMERA PROFILE
- Fast: 640x480, quicker startup and lower load.
- Quality: 1280x720, more source detail and potentially better tracking at difficult angles.
- Stop recording before changing profile.

SAFETY / DATA RULES
- COM connect/disconnect is blocked while recording.
- Camera profile changes are blocked while recording.
- Existing IMUCAL frame schema is unchanged.
