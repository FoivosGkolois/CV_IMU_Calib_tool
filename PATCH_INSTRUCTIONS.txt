Vision-IMU — Fast webcam initialization patch

BASELINE
Thesis_master(40) with Vision_IMU_Dual_IMU_Sync_Patch applied.

AFFECTED AREA
- Windows USB webcam startup only.
- Vision-only and synchronized Vision-IMU launchers.

MAIN CHANGE
- Default camera mode: 640x480 at 30 FPS.
- Windows automatic backend order: DSHOW -> MSMF -> OpenCV default.
- Optional explicit backend:
  --camera-backend dshow
  --camera-backend msmf
  --camera-backend default
  --camera-backend auto

WHY
MoveNet Thunder internally resizes its input to 256x256.
Negotiating 1280x720 therefore delayed camera startup without a useful
pose-estimation benefit for this controlled calibration workflow.

COPY / REPLACE
Extract this ZIP into the current Thesis_master root.
Keep the folder structure and replace the six matching files.
No file is deleted.

RUN
1. 10_TEST_VISION_IMU_PC.bat
   The complete targeted Vision-IMU suite should pass.

2. Vision only:
   09_RUN_VISION_IMU_PC.bat

3. Camera + UNO R4 IMUs:
   11_RUN_VISION_IMU_SYNC_PC.bat

EXPECTED
- Camera preview begins faster.
- Runtime source shows the selected backend, for example:
  camera:0 [DSHOW]

IF AUTO IS STILL SLOW
Run the working backend explicitly from the project root:

.venv-vision\Scripts\python.exe -m computer.vision_imu_calibration --camera 0 --camera-backend dshow --width 640 --height 480

Replace dshow with msmf if the Runtime source previously showed MSMF.
