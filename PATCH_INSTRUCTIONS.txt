Vision-IMU — Standalone runtime/test fix

ROOT CAUSE
The calibration tool was being run from a standalone folder rather than the
complete Thesis_master tree. Three repo-only assumptions remained:
1. settings/current.yaml had to exist,
2. STM32 knee_angle.cpp/.h had to exist for the parity test,
3. Matplotlib tried to open the Tk GUI backend.

AFFECTED AREA
- Knee-filter configuration resolution
- Headless acquisition plot export
- Standalone/full-repository test behavior

BEHAVIOR AFTER PATCH
- Explicit --filter-config remains strict.
- Without --filter-config:
  1. settings/current.yaml is preferred when present,
  2. otherwise the bundled Thesis_master(40) parameter snapshot is used.
- The active configuration path is still displayed and recorded.
- C++ parity test runs in the full thesis tree and is skipped in a standalone copy.
- Plot generation uses Matplotlib Agg and does not require Tk/Tkinter.
