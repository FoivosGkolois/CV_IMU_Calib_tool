PURPOSE
Complete the geometry half of Patch 1 without crossing into Patch 2 camera-
calibration persistence or Patch 3 IMU-calibration science.

MAIN CHANGES
- Adds a CameraCalibration contract for calibrated intrinsics and image size.
- Adds 3-D pose estimation for Tag 0 / Tag 1 using OpenCV IPPE square pose.
- Computes posterior knee angle from the two 3-D segment directions:
  180 deg = collinear extension, decreasing with flexion.
- Common 3-D body/camera misalignment largely cancels because the result uses
  relative segment orientation.
- Adds fixed, non-user-tunable quality gates for marker size, viewing obliquity,
  positive depth, reprojection consistency, and camera-resolution match.
- Records per-frame pose validity, reprojection RMSE, and view angle.
- GUI reports the live 3-D angle and quality metrics once a calibrated camera
  model is supplied.
- Keeps the 3-D result invalid with reason reference_setup_required until Patch
  2.1 supplies persistent checkerboard calibration.
- Adds an explicit migration gate so the legacy scientific IMU-calibration
  workflow cannot become active accidentally before Patch 3.
- Consolidates obsolete patch notes and removes the leftover MoveNet model.
- Rebuilds the UNO Q App Lab ZIP.

PHYSICAL TAG CONTRACT

- Tag 0 = thigh; Tag 1 = shank.
- Black square side = 70.0 mm.
- Both tags rigidly mounted.
- Printed TOP edge points proximally:
  thigh -> hip; shank -> knee.

IMPORTANT INTERMEDIATE-STATE BEHAVIOR
Patch 1.2 does not yet have real camera intrinsics. Therefore normal hardware
operation must continue to show camera calibration/reference setup required.
This is deliberate. A valid 3-D live reference becomes possible only after
Patch 2.1 loads a calibrated camera model matching the processed image size.
There is no uncalibrated 2-D fallback.
