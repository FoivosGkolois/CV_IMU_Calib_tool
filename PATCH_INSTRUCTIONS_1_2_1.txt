PURPOSE
Make UNO Q App Lab web-GUI startup explicit and diagnosable.

CHANGED FILES
- standalone_tools/vision_imu_calibration/uno_q_phase2_app_lab_template/python/main.py
- standalone_tools/vision_imu_calibration/uno_q_phase2_app_lab_template/README.md
- computer/tests/test_vision_imu_uno_q_phase2.py
- uno_q_phase2_app_ready.zip (rebuilt App Lab import package)

NO FILES NEED TO BE DELETED.

APPLY
1. Extract this patch into the root of CV_IMU_Calib_tool.
2. Replace existing files when prompted.
3. In Arduino App Lab, Stop/delete the previously imported Vision IMU app.
4. Import the new uno_q_phase2_app_ready.zip from the project root.
5. Press Run.
6. Watch the App launch terminal.
7. Do not open the browser until this line appears:
       [VISION-IMU] WEB GUI READY
8. Copy/paste the URL printed immediately below it that matches the UNO Q IPv4 shown by App Lab.

EXPECTED FAILURE BEHAVIOR
If the web runtime does not start, the App launch terminal now prints either:
- [VISION-IMU] WEB GUI DID NOT START
or
- [VISION-IMU] WEB GUI STARTUP TIMEOUT
with diagnostic information. The launcher exits instead of silently leaving an apparently-running App with no web service.
