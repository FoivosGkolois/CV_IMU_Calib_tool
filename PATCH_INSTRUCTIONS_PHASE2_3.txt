CV_IMU_Calib_tool — Phase 2.3 Automatic Camera Detection Patch

BASELINE
Built from the supplied CV_IMU_Calib_tool(3).zip source tree.
This patch preserves the existing Phase 2.1 and Phase 2.2 changes.

CHANGES
1. Automatic camera selection
   - The default camera selector is now "auto".
   - Linux enumerates all /dev/video* nodes.
   - UVC/webcam nodes are prioritized.
   - Internal Qualcomm encoder/decoder nodes are de-prioritized.
   - Every candidate must return a real frame before it is accepted.
   - An explicit --camera N override remains available.

2. Backend and format fallback
   - Linux tries V4L2 and the OpenCV default backend.
   - MJPG is tried first for UVC webcams, followed by the driver default format.
   - Windows keeps DSHOW -> MSMF -> default fallback.

3. App Lab portability
   - VISION_IMU_CAMERA_INDEX defaults to auto instead of 0.
   - Camera backend, width, height, and FPS can be overridden with:
     VISION_IMU_CAMERA_BACKEND
     VISION_IMU_CAMERA_WIDTH
     VISION_IMU_CAMERA_HEIGHT
     VISION_IMU_CAMERA_FPS

4. Diagnostics
   - /api/status camera payload now reports:
     selector
     active_index
     source
   - Error messages are platform-specific instead of always mentioning Windows.

5. Rebuilt App Lab package
   - uno_q_phase2_app_ready.zip contains the updated runtime.
