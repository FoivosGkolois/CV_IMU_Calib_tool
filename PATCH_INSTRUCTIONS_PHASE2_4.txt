CV_IMU_Calib_tool — Phase 2.4 Deterministic Exports + Responsive GUI Patch

BASELINE
Built from the supplied CV_IMU_Calib_tool(5).zip source tree.
This patch preserves the existing Phase 2.1, 2.2, and 2.3 changes.

OBJECTIVE
Make recorder/calibration output ownership deterministic and portable, expose
clickable browser exports, and remove user-resizable GUI boxes.

OUTPUT OWNERSHIP
1. Simple Record Video owner
   CV_IMU_Calib_tool/video_recordings/
   - Creates only vision_imu_session_<timestamp>.zip files.
   - Never writes into calibration_suggestions.

2. CalibrationWorkflow owner
   CV_IMU_Calib_tool/calibration_suggestions/calibration_run_<timestamp>/
   - One run ID and one directory for the complete two-stage calibration.
   - Static and dynamic use the same run directory.
   - Never writes into video_recordings.

3. Recording engine
   - Does not choose calibration folders.
   - Receives an owned output root and exact archive name from the workflow.
   - Refuses to overwrite deterministic stage archives.

CALIBRATION STATE FLOW
IDLE
-> RUNNING_STATIC
-> ANALYZING_STATIC
-> AWAITING_DYNAMIC
-> RUNNING_DYNAMIC
-> ANALYZING
-> COMPLETE / INVALID

CALIBRATION RUN CONTENTS
calibration_suggestions/calibration_run_<timestamp>/
- static_trial.zip
- dynamic_trial.zip
- imu_filter_suggestions.yaml
- calibration_report.json
- calibration_overview.png

SHARED YAML
- Created at run start.
- Atomically updated after the static stage with static_stage.suggestion and
  status: awaiting_dynamic.
- Atomically updated after the dynamic stage with dynamic_stage.suggestion,
  final_recommended_settings, and status: complete.
- Failure/cancel states keep the YAML synchronized with the retryable workflow.
- Final complete YAML remains loadable by the existing IMU filter loader.

PORTABLE CLICKABLE EXPORTS
- Internal absolute paths are retained only for filesystem operations.
- GUI/API display only project-relative paths.
- Browser routes list/open/download owned exports:
  /exports/recordings/
  /exports/calibration/
- Path traversal outside the owned roots is rejected.
- No os.startfile, Explorer, xdg-open, or machine-specific path is used.

RESPONSIVE GUI
- Removes resize handles, localStorage size persistence, and Custom layout card.
- Cards, camera, controls, and plot resize automatically with page width.
- Desktop, laptop, and narrow-screen breakpoints remain deterministic.

COPY / REPLACE
Extract this patch ZIP directly inside the current CV_IMU_Calib_tool folder.
Allow replacement of all included files.

DELETE
None.

APP LAB REDEPLOYMENT
1. Stop the currently running Vision IMU App Lab app.
2. Delete the old imported app.
3. Close and reopen Arduino App Lab.
4. Import the replaced project-root file:
   uno_q_phase2_app_ready.zip
5. Run the app and reload the browser with Ctrl+F5.
