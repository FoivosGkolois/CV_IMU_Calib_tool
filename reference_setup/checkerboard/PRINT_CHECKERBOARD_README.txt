PATCH 2.1 CAMERA CALIBRATION CHECKERBOARD

Pattern: 9 x 6 INNER corners = 10 x 7 squares
Square size: 25 mm
Board size: 250 x 175 mm
Page: A4 landscape

PRINTING
- Print checkerboard_9x6_25mm_A4_landscape.svg at 100% / Actual Size.
- Disable Fit to Page / Shrink / Scale.
- Measure one square after printing: it must be 25 x 25 mm.
- Use matte paper and keep the sheet flat on a rigid backing.
- Do not laminate with a glossy surface.

USE
1. Keep the same camera, resolution/profile and physical lens setup that will be used with the AprilTags.
2. In the browser tool press Start checkerboard calibration.
3. Move and tilt the board across the camera view. The tool automatically accepts diverse views.
4. Continue until 15/15 accepted views.
5. A successful Patch 2.1 calibration is applied only to the current running session. Patch 2.2 will persist it across restarts.
