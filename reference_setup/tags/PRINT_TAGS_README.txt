APRILTAG REFERENCE — PRINTING AND MOUNTING CONTRACT

Dictionary: AprilTag 36h11
Tag 0: THIGH
Tag 1: SHANK
Black-square size: 70.0 mm x 70.0 mm

PRINTING
- Prefer the SVG files.
- Print at 100% / Actual Size. Do not use Fit to Page.
- Verify the outer black square is 70.0 mm x 70.0 mm.
- Keep the surrounding white margin.
- Use matte paper on rigid flat backing; avoid glossy reflections and bending.

REUSABLE RIGID PLATE
- Mount each printed tag to a rigid reusable plate (for example thin matte PVC/Forex or rigid foamboard).
- Use the same physical tag plates for the known-angle fixture validation and on the exoskeleton.
- Velcro/3M Dual Lock may be used on the back, provided the plate cannot rotate or flex.

ORIENTATION
- Keep each tag upright exactly as printed.
- TOP edge points PROXIMALLY along the segment:
  Tag 0 / thigh: toward the hip.
  Tag 1 / shank: toward the knee.
- Do not rotate a tag by 90 or 180 degrees.

ONE-TIME KNOWN-ANGLE VALIDATION
After camera calibration, attach the same plates to a rigid hinged fixture/goniometer and validate 180, 150, 120 and 90 degrees with five captures per angle. The result is saved persistently on the UNO Q.
