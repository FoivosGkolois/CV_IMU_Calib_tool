APRILTAG REFERENCE — PRINTING AND MOUNTING CONTRACT

Dictionary: AprilTag 36h11
Tag 0: THIGH
Tag 1: SHANK
Black-square size: 70.0 mm x 70.0 mm

PRINTING
- Prefer the SVG files.
- Print at 100% / Actual size. Do not use Fit to page.
- Verify the outer black square is 70.0 mm x 70.0 mm.
- Keep the surrounding white margin.
- Use matte paper and rigid flat backing; avoid glossy reflections and bending.

MOUNTING ORIENTATION — IMPORTANT FOR THE 3-D ANGLE
- Keep each tag in the same upright orientation as the file is displayed/printed.
- The TOP edge of each printed tag must point PROXIMALLY along the segment:
  Tag 0 / thigh: top edge -> toward the hip.
  Tag 1 / shank: top edge -> toward the knee.
- Mount the tags rigidly on the corresponding exoskeleton/IMU carriers.
- Do not rotate one tag by 90 or 180 degrees relative to this convention.

The IDs, physical size, rigidity, and orientation are part of the geometric
reference contract. Patch 1.2 contains the calibrated 3-D geometry and fixed
quality gates; Patch 2.1 supplies the persistent camera calibration required to
activate a valid live reference angle.
